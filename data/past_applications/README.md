# 과거 신청서를 여기에 넣으세요

이 폴더의 문서는 두 가지에 쓰입니다.

1. **초안 생성의 참고 자료** — 새 공고의 항목마다 비슷한 문항을 찾아 문체와 내용을
   참고합니다(`tools/past_search.py`). 여기가 비어 있으면 회사 프로필만 가지고 쓰게
   되어 초안이 짧고 일반적인 글이 됩니다.
2. **튜닝 학습 데이터** — `python -m tools.export_training` 이 이 폴더를 읽어
   CLOVA Studio 학습용 CSV를 만듭니다.

## 넣는 방법

실제로 제출했던 신청서를 `.md` 파일로 저장하고, 문항을 `##` 제목으로 나눕니다.

```markdown
# 2025년 스마트공장 구축지원사업 신청서 (제출본)

## 사업 개요
당사는 차량용 전자제어 모듈(ECU) PCB 어셈블리를 생산하는 …

## 추진 배경 및 필요성
생산 실적과 불량 이력이 수기 대장으로 관리되고 있어 …
```

문항 단위로 검색하므로 `##` 로 나누는 게 중요합니다. 문서를 통째로 넣으면 새 공고의
'기대효과' 항목을 쓸 때 엉뚱한 문단을 참고합니다.

넣을수록 초안이 구체적이고 길어집니다. 연습용 예시는 실제 공고와 섞이지 않도록
모두 걷어냈습니다.
